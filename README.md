# 👗 Laiba's Boutique - Mobile App

A luxury fashion boutique mobile app built with React, featuring AI-powered style recommendations.

## ✨ Features

- **Splash Screen** with animated logo and loading bar
- **Home Page** - Hero carousel, AI style tips, promo banners, product grid
- **Search Page** - Real-time search + AI-powered style suggestions
- **Wishlist Page** - Save your favorite items
- **Cart Page** - Manage cart, quantity control, checkout
- **Profile Page** - User stats, AI stylist, settings menu
- **Bottom Tab Navigation** - Home, Search, Wishlist, Cart, Profile
- **Claude AI Integration** - Live style tips & personalized advice
- **Luxury Animations** - Page transitions, shimmer effects, card animations
- **Green & Gold Theme** - Elegant boutique aesthetic

## 🚀 How to Run

1. **Double-click `index.html`** to open in browser
   - OR: Open with any modern browser (Chrome, Firefox, Edge, Safari)
   - Note: For AI features to work, internet connection is required

2. The app runs fully in the browser — no install needed!

## 📱 Mobile Preview
The app is designed for mobile (430px max-width) and looks best on mobile or in browser devtools mobile view.
